# v0.4.0-beta.2 Windows 发布记录

发布页：[Trail · 研迹 v0.4.0-beta.2](https://github.com/ydflow/Trail/releases/tag/v0.4.0-beta.2)。交付 Windows x64 NSIS 安装版和便携版，保留 Beta 标识。两种程序均未进行 Authenticode 数字签名，不包含自动更新配置。

## 下载与配置

- [安装版](https://github.com/ydflow/Trail/releases/download/v0.4.0-beta.2/Trail-0.4.0-beta.2-windows-x64-setup.exe)：当前用户安装，可选择目录，通过开始菜单启动，可在 Windows 设置中卸载。
- [便携版](https://github.com/ydflow/Trail/releases/download/v0.4.0-beta.2/Trail-0.4.0-beta.2-windows-x64-portable.exe)：直接运行；会解压运行文件到临时目录，用户研究记录仍保存在本机用户数据目录，并非随 EXE 携带。
- [SHA256SUMS.txt](https://github.com/ydflow/Trail/releases/download/v0.4.0-beta.2/SHA256SUMS.txt)：用 `Get-FileHash .\Trail-0.4.0-beta.2-windows-x64-setup.exe -Algorithm SHA256` 核对。

Windows 可能提示发布者未知。AI 功能需另行安装 Bun、联网获取 Pi 运行时，并在设置中配置自己的模型。行情需另行安装并授权官方 Longbridge CLI；不附带模型密钥或长桥账户。首次引导完成不代表这些外部服务已就绪。源码、macOS 和 Linux 的启动入口见 [README](../../README.md#快速开始)。

## 构建来源

应用业务代码来自现有标签 `v0.4.0-beta.2`，SHA 为 `09e6e52759f91fff4345de3f90bff81128484003`；此次没有移动标签。Windows 打包修订为 `windows.1`，增加的 `windows-entry.cjs` 复用该标签内 `start-trail.cmd` 的路径处理：发现 npm 安装的原生 `bunx.exe`，以及标准用户目录内的 Longbridge CLI，然后加载原有主进程。尊重显式设置的 `FINAGENT_PI_COMMAND`。

使用 Node.js 24.19.0、Bun 1.4.2、Electron 39.8.9、electron-builder 26.8.1 构建。包内包含 renderer/main/preload、13 个技能、finagent 与 langsmith 扩展；Bun、Pi CLI 和 Longbridge CLI 不内嵌。`BUILDINFO.json` 记录来源和验收范围，`SHA256SUMS.txt` 校验两个 EXE 及构建说明附件。

本次打包配方保存于 [scripts/package-windows.cjs](../../scripts/package-windows.cjs)，发布页另附同内容的 `windows-packaging.cjs`。它只打包，不上传：先在标签源码中安装依赖并运行 `bun run build`、`bun run --cwd apps/electron build:extension`，把配方放到源码的 `scripts` 目录，再运行 `node scripts/package-windows.cjs`。输出位于 `dist/windows-v0.4.0-beta.2`。`--prepare-only` 仅生成 staging 与配置。依赖解析和运行时下载可能随时间变化，不宣称逐字节可复现。

本机曾因 Windows 禁止创建符号链接而无法解压 electron-builder 的 winCodeSign 辅助包。构建使用官方已下载的 2.6.0 辅助包，在独立工具缓存内排除了仅用于 macOS 的 `darwin` 目录，保留原 Windows rcedit 工具；未关闭 EXE 图标或资源编辑。重建时可启用 Windows 开发人员模式，或使用同样的独立缓存处理。
