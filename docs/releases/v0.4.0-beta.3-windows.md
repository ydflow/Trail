# v0.4.0-beta.3 Windows 发布记录

发布页：[Trail · 研迹 v0.4.0-beta.3 Windows x64](https://github.com/ydflow/Trail/releases/tag/v0.4.0-beta.3-windows)。

## 本次更新

将当前主线的助手体验更新同步到安装包：更清晰的会话列表、会话重命名、助手放大/还原/收起、主页研迹助手入口，以及重新布局的独立助手与新会话页。README、社区讨论和 Personal Agent Roadmap 同步到仓库；路线图中的 Pi Durable、长期记忆和 Harness² × RSI 属于未来规划，未作为本版交付能力。

AI 功能仍需 Bun、模型配置和可用的 Pi runtime；行情需自行安装并授权 Longbridge CLI。安装包不包含账户、密钥、Bun 或 Longbridge CLI。安装成功不代表这些外部服务已经就绪。

## 构建来源与配方

业务构建来源为提交 `560cd5a25deae2ce62df243b1286d9076e704992`，应用版本 `0.4.0-beta.3`，Windows 修订 `windows.1`。发布标签为 `v0.4.0-beta.3-windows`，用于区分现有 macOS 标签上传工作流；工作流对此 Windows 标签跳过 macOS 构建与上传，避免覆盖 Windows 发布说明。标签固定在上述构建提交，不移动 beta.2。

环境：Windows x64、Node 24.19.0、Bun 1.4.2、Electron 39.8.9、electron-builder 26.8.1。

```text
bun install --frozen-lockfile
bun test --isolate
bun run typecheck
bun run build
bun run --cwd apps/electron build:extension
node scripts/package-windows.cjs
node apps/electron/e2e/assistant-workspace.mjs
```

[Windows 配方](../../scripts/package-windows.cjs) 读取当前应用版本和 HEAD，拒绝未提交的受跟踪改动，输出至 `dist/windows-v<version>`。Windows 入口沿用原先的 Bun/长桥路径发现逻辑。构建复用了 beta.2 的独立 electron-builder 工具缓存，其 Windows 符号链接处理记录见 [beta.2 发布记录](v0.4.0-beta.2-windows.md)。环境与依赖下载可能变化，不保证逐字节可复现。

验证使用隔离的合成数据、本地确定性 runtime 与示例行情；没有修改用户真实会话。首次引导脚本因已连接的示例状态跳过向导而误判，改为隔离未配置环境后通过；隐藏窗口回归启用不节流后通过。便携自解压启动器不适合直接用 Playwright Electron 启动器握手，改用其实际解压进程的本地 CDP 验证；正常关闭导致的连接断开也已从清理误报中区分。

本次没有重新验收真实模型/长桥账户接线、完整 macOS 专用 release:check 套件、数字签名、macOS/Linux/ARM64、其他 Windows 设备或所有旧版本迁移。beta.2 的真实服务历史证据见其发布记录，不作为 beta.3 的新验收结果。
